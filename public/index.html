How I built this

This site was built and shipped with AI coding agents, with me as the reviewer and final gate.

  • A builder agent (Claude Code) works one GitHub Issue at a time on a branch and opens a pull request.
  • A separate checker agent writes Playwright end-to-end tests from a written specification only. It never sees the site's code, so tests check what was asked, not what was built.
  • Every pull request runs those tests in GitHub Actions. A pull request cannot merge until they pass and I have reviewed it.
  • Merging to main deploys the site to GitHub Pages automatically.

  4. Checker's tests
