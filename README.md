# Bryce-site

Personal portfolio website, built with plain HTML, CSS and a little vanilla JavaScript. No frameworks, no build step.

## Structure

Site files live in `public/`.

## Local preview

Open `public/index.html` in a browser, or serve the folder:

```sh
python3 -m http.server --directory public
```

## Deploy

Pushing to `main` triggers GitHub Actions, which publishes the site to GitHub Pages.
